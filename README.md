# My家計簿

iPhoneのSafariからホーム画面へ追加して使う、自分専用の家計簿PWAです。現在は **Phase 5（月予算）** まで実装しています。

## 実装済み

### Phase 1：アプリ基盤

- React + TypeScript + Vite
- TypeScript strict mode
- iPhone優先のレスポンシブUI、Safe Area、ライト・ダークモード
- PWA manifest、Service Worker、オフライン用アプリシェル、更新通知
- GitHub Pagesのサブパス対応とGitHub Actionsによる自動検査・デプロイ
- React移行前のLocalStorageデータを確認・書き出しできる旧版互換画面

### Phase 2：IndexedDB保存基盤

- Dexieを使用した端末内IndexedDB
- 収支、カテゴリ、支払い方法、予算、通知状態、設定、アプリ情報の型とテーブル
- 初期マスターデータ、データバージョン、マイグレーション
- Repository層とfake-indexeddbによる保存テスト

### Phase 3：収支管理

- 支出・収入の手入力
- 金額は日本円・1円単位で、0円以下は登録不可
- 日付は今日を初期値として変更可能
- 支出：カテゴリ、支払い方法が必須。店名・内容は任意
- 収入：カテゴリが必須。内容は任意
- 月単位の切替と日付ごとのグループ表示
- 店名・内容の検索と各種絞り込み
- 詳細表示、編集、削除確認
- 一覧表示項目の選択
- カテゴリと支払い方法の管理

### Phase 4：集計とホーム

- 選択月の収入・支出・残額
- 前月との差額
- カテゴリ別支出の円グラフ
- 支払い方法別集計
- 収支一覧の絞り込み結果集計
- 支出0件時の空状態

### Phase 5：月予算

- 月全体の予算設定・変更・削除
- 月途中の予算変更後に残額と使用率を再計算
- 月予算、使用額、残額または超過額、使用率を表示
- 使用率100%超の予算超過状態を表示
- 前月の正の未使用予算を翌月へ繰り越す設定
- 超過額は翌月へ繰り越さない
- 過去月の支出・予算変更後に翌月以降の繰越額を再計算
- ホーム画面に選択月の予算状況を表示
- 予算未設定時の案内
- 予算データと繰越設定をIndexedDBへ保存

カテゴリ別予算は全体仕様の対象外です。通知、CSV、PDF、バックアップ、レシート入力は後続フェーズです。

## Phase 5の手動確認

1. 予算タブを開き、選択月の予算が未設定と表示されることを確認します。
2. 0円、負数、小数では保存できないことを確認します。
3. 月予算を設定し、予算額・使用額・残額・使用率が正しいことを確認します。
4. 月途中で予算額を変更し、使用額は変わらず残額と使用率が更新されることを確認します。
5. 支出が予算額を超えた場合、超過状態と超過額が表示されることを確認します。
6. 繰越をONにし、前月と翌月の両方に予算を設定します。
7. 前月の未使用額が翌月の有効予算へ加算されることを確認します。
8. 前月が予算超過の場合、負の超過額が翌月へ繰り越されないことを確認します。
9. 前月の支出または予算を変更し、翌月の繰越額が再計算されることを確認します。
10. 繰越をOFFにし、翌月の繰越額が0円へ戻ることを確認します。
11. ホーム画面へ戻り、同じ選択月の予算状況が表示されることを確認します。
12. 月予算を削除し、ホームと予算画面が未設定表示へ戻ることを確認します。
13. iPhone幅とライト・ダークモードで表示が崩れないことを確認します。

## IndexedDBの確認

開発者ツールの **Application > Storage > IndexedDB > my-kakeibo** で次を確認します。

- `monthlyBudgets`：月予算、繰越額、有効予算
- `budgetSettings`：月予算の繰越ON/OFF
- `transactions`：集計元の収支

家計簿データと予算データは端末内に保存され、外部へ送信されません。

## GitHub Pages

`main`ブランチへpushすると`.github/workflows/deploy-pages.yml`がlint、型検査、テスト、ビルドを実行し、成功後にGitHub Pagesへ公開します。Viteの`base`、manifestの`start_url`と`scope`はリポジトリのサブパスに合わせて設定されます。

## 旧版データへのアクセス

React移行前の記録は、同じオリジンのLocalStorageに`kurashi-kakeibo-v1`として保存されています。新しいアプリの **設定 > 旧版データ > 旧版の家計簿を開く** から確認・JSON書き出しができます。Phase 5では旧版データを自動削除・自動変換しません。

## データ保存とプライバシー

新しい家計簿データの保存先は、iPhoneまたはブラウザ内のIndexedDBです。集計と予算計算は端末内で行い、家計簿データをGitHubリポジトリや外部サーバーへ保存・送信しません。ブラウザのWebサイトデータを削除した場合、端末内データも失われる可能性があります。
