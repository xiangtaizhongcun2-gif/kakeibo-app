# My家計簿

iPhoneのSafariからホーム画面へ追加して使う、自分専用の家計簿PWAです。現在は **Phase 4（集計とホーム）** まで実装しています。

## 実装済み

### Phase 1：アプリ基盤

- React + TypeScript + Vite
- TypeScript strict mode
- iPhone優先のレスポンシブUI、Safe Area、ライト・ダークモード
- PWA manifest、Service Worker、オフライン用アプリシェル、更新通知
- GitHub Pagesのサブパス対応とGitHub Actionsによる自動検査・デプロイ
- React移行前のLocalStorageデータを確認・書き出しできる旧版互換画面

### Phase 2：IndexedDB保存基盤

- Dexieを使用した端末内IndexedDB
- 収支、カテゴリ、支払い方法、予算、通知状態、設定、アプリ情報の型とテーブル
- 初期マスターデータ、データバージョン、マイグレーション
- Repository層とfake-indexeddbによる保存テスト

### Phase 3：収支管理

- 支出・収入の手入力
- 金額は日本円・1円単位で、0円以下は登録不可
- 日付は今日を初期値として変更可能
- 支出：カテゴリ、支払い方法が必須。店名・内容は任意
- 収入：カテゴリが必須。内容は任意。受取方法・入金先は記録しない
- 月単位の切替と日付ごとのグループ表示
- 新しい日付・登録時刻を上に表示
- 店名・内容の検索
- 種類・日付・カテゴリ・支払い方法による絞り込み
- 詳細表示、編集、削除確認
- 一覧表示項目の選択
- 支出・収入カテゴリの追加、表示・非表示
- 支払い方法の追加と削除
- 使用中の支払い方法を削除した場合、過去データを「未設定」へ変更

### Phase 4：集計とホーム

- 選択月の収入・支出・残額（収入−支出）をホームに表示
- 収入・支出の件数を表示
- 前月との収入・支出・残額の差額を表示
- カテゴリ別支出を円グラフで表示
- 円グラフまたは凡例のタップで、カテゴリの金額と全支出比率を表示
- 支払い方法別に利用額、件数、全支出比率を表示
- ホームから支払い方法別集計の詳細画面を表示
- 収支一覧の検索・絞り込み結果に対する収入・支出・残額の集計
- 収支一覧の検索・絞り込み結果に対する支払い方法別集計
- 支出0件時の空状態
- 集計ロジックをUI・IndexedDB処理から分離

予算計算、通知、CSV、PDF、バックアップ、レシート入力は後続フェーズです。

## Phase 4の手動確認

1. 同じ月に収入と複数カテゴリ・支払い方法の支出を登録します。
2. ホームで収入、支出、残額が正しいことを確認します。
3. 前月にも収支を登録し、前月との差額が正しいことを確認します。
4. ホームの月切替と収支一覧の月切替が同じ選択月を共有することを確認します。
5. カテゴリ別円グラフまたは凡例をタップし、金額と全支出比率が切り替わることを確認します。
6. 支払い方法別に利用額、件数、全支出比率が表示されることを確認します。
7. 「すべて見る」から支払い方法別集計の詳細画面を開きます。
8. 収支一覧で検索・絞り込みを行い、「表示中の収支集計」が結果に追従することを確認します。
9. 支出がない月ではエラーではなく空状態が表示されることを確認します。
10. ライトモードとダークモード、iPhone幅で円グラフ・カード・詳細画面が崩れないことを確認します。

## IndexedDBの確認

1. 開発者ツールの **Application > Storage > IndexedDB > my-kakeibo** を開きます。
2. Phase 4の集計専用データが新規保存されていないことを確認します。
3. 集計は`transactions`の既存データから都度計算され、家計簿データが外部送信されていないことを確認します。

## GitHub Pages

`main`ブランチへpushすると`.github/workflows/deploy-pages.yml`がlint、型検査、テスト、ビルドを実行し、成功後にGitHub Pagesへ公開します。Viteの`base`、manifestの`start_url`と`scope`はリポジトリのサブパスに合わせて設定されます。

## 旧版データへのアクセス

React移行前の記録は、同じオリジンのLocalStorageに`kurashi-kakeibo-v1`として保存されています。新しいアプリの **設定 > 旧版データ > 旧版の家計簿を開く** から確認・JSON書き出しができます。Phase 4では旧版データを自動削除・自動変換しません。

## データ保存とプライバシー

新しい家計簿データの保存先は、iPhoneまたはブラウザ内のIndexedDBです。集計は端末内で行い、家計簿データをGitHubリポジトリや外部サーバーへ保存・送信しません。ブラウザのWebサイトデータを削除した場合、端末内データも失われる可能性があります。
