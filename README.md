# My家計簿

iPhoneのSafariからホーム画面へ追加して使う、自分専用の家計簿PWAです。現在は **Phase 7（CSV・PDF出力）** まで実装しています。

## 実装済み

### Phase 1：アプリ基盤

- React + TypeScript + Vite
- TypeScript strict mode
- iPhone優先のレスポンシブUI、Safe Area、ライト・ダークモード
- PWA manifest、Service Worker、オフライン用アプリシェル、更新通知
- GitHub Pagesのサブパス対応とGitHub Actionsによる自動検査・デプロイ
- React移行前のLocalStorageデータを確認・書き出しできる旧版互換画面

### Phase 2：IndexedDB保存基盤

- Dexieを使用した端末内IndexedDB
- 収支、カテゴリ、支払い方法、予算、通知状態、設定、アプリ情報の型とテーブル
- 初期マスターデータ、データバージョン、マイグレーション
- Repository層とfake-indexeddbによる保存テスト

### Phase 3：収支管理

- 支出・収入の手入力
- 金額は日本円・1円単位で、0円以下は登録不可
- 月単位の切替、検索、絞り込み、詳細、編集、削除
- カテゴリと支払い方法の管理

### Phase 4：集計とホーム

- 選択月の収入・支出・残額
- 前月との差額
- カテゴリ別支出の円グラフ
- 支払い方法別集計
- 収支一覧の絞り込み結果集計

### Phase 5：月予算

- 月全体の予算設定・変更・削除
- 月予算、使用額、残額または超過額、使用率を表示
- 前月の正の未使用予算を翌月へ繰り越す設定
- 過去月の支出・予算変更後に翌月以降の繰越額を再計算
- ホーム画面に選択月の予算状況を表示

### Phase 6：予算超過通知

- 月予算を実際に超えたときだけ通知
- アプリ内通知と対応環境でのシステム通知
- 通知権限は設定画面のボタン操作時だけ要求
- 同じ月・同じ通知方法では1回だけ通知
- 通知設定と通知済み状態をIndexedDBへ保存

### Phase 7：CSV・PDF出力

- 選択月の全収支をCSVへ出力
- 開始日と終了日を指定した期間CSV
- 収支一覧で現在表示中の検索・絞り込み結果だけをCSVへ出力
- UTF-8 BOM付きCSVで日本語の文字化けを軽減
- カンマ、改行、引用符をCSV形式に合わせてエスケープ
- Web Share APIのファイル共有に対応する環境では共有シートを表示
- ファイル共有に非対応の場合はブラウザへCSVをダウンロード
- 月次家計簿レポートの印刷用画面を作成
- 月次レポートに収入、支出、残額、予算、カテゴリ別支出、支払い方法別支出、収支明細を掲載
- A4縦向けの印刷レイアウト
- ブラウザまたはOSの印刷画面からPDFとして保存・共有
- 日本語フォントやPDF変換サービスを外部から取得しない
- CSV・印刷用レポートは端末内だけで生成

カテゴリ別予算とカテゴリ別通知は全体仕様の対象外です。バックアップ、復元、レシート入力は後続フェーズです。

## CSVの列

CSVには次の順序で出力します。

1. 日付
2. 種類
3. 金額（円）
4. カテゴリ
5. 支払い方法
6. 店名
7. 内容

収入では支払い方法と店名を空欄にします。出力順は日付が古いものから、新しいものへの順です。

## PDF出力方式

Phase 7では、アプリが端末内で日本語の印刷用HTMLレポートを作成し、ブラウザの印刷画面を開きます。印刷画面から「PDFとして保存」または共有を選択します。

この方式により、次を避けています。

- 家計簿データの外部PDF変換サービスへの送信
- 外部日本語フォントの取得
- サーバー側でのファイル生成

アプリから直接PDFバイナリを生成する方式ではありません。最終的なPDF保存操作はブラウザまたはOSの印刷画面で行います。

## Phase 7の手動確認

### 月単位CSV

1. 同じ月に支出と収入を複数登録します。
2. 設定画面の「CSV・PDF出力」を開きます。
3. 対象月を選択します。
4. 「月のCSVを共有・保存」を押します。
5. 対象月以外の収支が含まれていないことを確認します。
6. 日付、種類、金額、カテゴリ、支払い方法、店名、内容が正しいことを確認します。
7. 日本語、カンマ、引用符を含む店名や内容が壊れていないことを確認します。
8. Excel、Numbers、Googleスプレッドシートなどで文字化けせず開けることを確認します。

### 指定期間CSV

1. 開始日と終了日を入力します。
2. 「指定期間のCSVを共有・保存」を押します。
3. 開始日と終了日を含む範囲だけが出力されることを確認します。
4. 開始日を終了日より後にした場合、エラーになり出力されないことを確認します。
5. 収支が0件の場合もヘッダーだけのCSVを作成できることを確認します。

### 表示中の結果CSV

1. 収支タブを開きます。
2. 店名・内容、種類、日付、カテゴリ、支払い方法で絞り込みます。
3. 「表示中をCSV出力」を押します。
4. 現在画面に表示されている収支だけがCSVへ含まれることを確認します。
5. 条件をクリアして再出力し、選択月の全収支へ戻ることを確認します。

### CSVの共有と保存

- ファイル共有に対応するiPhoneでは共有シートが表示されること
- 「ファイルに保存」、AirDrop、対応アプリなどを選択できること
- ファイル共有非対応のブラウザではCSVがダウンロードされること
- 共有をキャンセルした場合、アプリ本体がエラーで利用不能にならないこと

### 月次PDFレポート

1. 対象月に収支と月予算を登録します。
2. 設定画面で対象月を選択します。
3. 「PDFとして保存」を押します。
4. 新しい印刷用画面と印刷ダイアログが開くことを確認します。
5. 月次サマリーの収入、支出、残額が正しいことを確認します。
6. 月予算、繰越額、有効予算、残額または超過額、使用率が正しいことを確認します。
7. カテゴリ別支出と支払い方法別支出が正しいことを確認します。
8. 収支明細が日付の古い順に表示されることを確認します。
9. 印刷画面でPDFとして保存します。
10. 保存したPDFを開き、日本語の欠落、文字化け、表の切れ、重なりがないことを確認します。

### iPhoneでPDFを保存・共有

1. Safariまたはホーム画面へ追加したPWAから「PDFとして保存」を押します。
2. 印刷プレビューを開きます。
3. PDF保存または共有操作を行います。
4. 「ファイルに保存」などで端末へ保存します。
5. 保存後のPDFを開いてレイアウトを確認します。

端末やiOSのバージョンによって印刷プレビューからPDFを共有する操作が異なる場合があります。

## IndexedDBの確認

Phase 7は出力履歴や生成ファイルをIndexedDBへ保存しません。既存の次のデータを読み取って、その場で出力を作成します。

- `transactions`：CSVと明細の元データ
- `monthlyBudgets`：月次PDFレポートの予算情報
- 支出カテゴリ、収入カテゴリ、支払い方法：出力時の表示名

CSV、印刷用HTML、PDF保存操作のために家計簿データを外部サーバーへ送信しません。

## PWAとオフライン出力

アプリ本体と必要なJavaScriptがService Workerへキャッシュ済みで、IndexedDBを利用できる状態では、CSV作成と印刷用レポート作成を端末内で行います。ブラウザやOSの共有・印刷機能自体は端末環境に依存します。

## GitHub Pages

`main`ブランチへpushすると`.github/workflows/deploy-pages.yml`がlint、型検査、テスト、ビルドを実行し、成功後にGitHub Pagesへ公開します。Viteの`base`、manifestの`start_url`と`scope`、通知アイコンはリポジトリのサブパスに合わせて設定されます。Phase 7の出力画面は相対パスや外部PDFサービスを使用しないため、GitHub Pagesのサブパスでも動作します。

## 旧版データへのアクセス

React移行前の記録は、同じオリジンのLocalStorageに`kurashi-kakeibo-v1`として保存されています。新しいアプリの **設定 > 旧版データ > 旧版の家計簿を開く** から確認・JSON書き出しができます。Phase 7では旧版データを自動削除・自動変換しません。

## データ保存とプライバシー

新しい家計簿データ、予算、通知設定、通知済み状態の保存先は、iPhoneまたはブラウザ内のIndexedDBです。集計、予算計算、通知判定、CSV作成、印刷用レポート作成は端末内で行い、家計簿データをGitHubリポジトリや外部サーバーへ保存・送信しません。ブラウザのWebサイトデータを削除した場合、端末内データも失われる可能性があります。
