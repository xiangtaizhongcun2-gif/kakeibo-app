# My家計簿

iPhoneのSafariからホーム画面へ追加して使う、自分専用の家計簿PWAです。Phase 1〜8に加え、現在の貯金残高と1件の貯金目標を管理できます。

## 実装済み

### Phase 1：アプリ基盤

- React + TypeScript + Vite
- TypeScript strict mode
- iPhone優先のレスポンシブUI、Safe Area、ライト・ダークモード
- PWA manifest、Service Worker、オフライン用アプリシェル、更新通知
- GitHub Pagesのサブパス対応とGitHub Actionsによる自動検査・デプロイ

### Phase 2：IndexedDB保存基盤

- Dexieを使用した端末内IndexedDB
- 収支、カテゴリ、支払い方法、予算、通知、設定、アプリ情報の型とテーブル
- 初期データ、データバージョン、マイグレーション
- Repository層とfake-indexeddbによる保存テスト

### Phase 3：収支管理

- 支出・収入の手入力
- 月単位の切替、検索、絞り込み、詳細、編集、削除
- カテゴリと支払い方法の管理

### Phase 4：集計とホーム

- 選択月の収入・支出・残額
- 前月との差額
- カテゴリ別支出と支払い方法別集計
- 収支一覧の絞り込み結果集計

### Phase 5：月予算

- 月全体の予算設定・変更・削除
- 使用額、残額または超過額、使用率
- 前月の正の未使用予算を翌月へ繰り越す設定

### Phase 6：予算超過通知

- 月予算を実際に超えたときだけ通知
- アプリ内通知と対応環境でのシステム通知
- 同じ月・同じ通知方法では1回だけ通知

### Phase 7：CSV・PDF出力

- 選択月、指定期間、表示中の収支をCSVへ出力
- 月次家計簿レポートの印刷用画面
- ブラウザまたはOSの印刷機能によるPDF保存・共有

### Phase 8：バックアップ・復元

- IndexedDB内の全データと設定を1つのJSONへバックアップ
- 復元前の形式・型・金額・日付・重複・参照整合性検証
- 最終確認後に現在データを完全置換
- 全テーブルを1つのDexieトランザクションで復元
- 途中失敗時の全変更ロールバック

### 追加機能：貯金残高・目標

- 現在の貯金残高を手入力
- 目標名と目標金額を1件設定
- ホーム画面に残高、目標、達成率、目標までの残額を表示
- 目標達成後は100％以上の実際の達成率を表示
- 目標だけを削除し、現在残高は維持
- 収入と支出からの自動計算は行わない
- IndexedDBの`savingsSettings`へ端末内保存
- バックアップと復元の対象に含める

カテゴリ別予算、カテゴリ別通知、レシート入力、OCRは実装対象外です。

## 貯金機能の仕様

貯金残高は月ごとの値ではなく、アプリ全体で共通の「現在残高」です。ホームで表示月を変更しても同じ残高を表示します。

目標は次の組み合わせで保存します。

- 目標名：40文字以内
- 目標金額：1円以上の整数

目標名と目標金額は両方を入力するか、両方を未設定にする必要があります。現在残高は0円以上の整数です。

## バックアップ対象

次のIndexedDBテーブルをバックアップします。

- `transactions`
- `expenseCategories`
- `incomeCategories`
- `paymentMethods`
- `monthlyBudgets`
- `categoryBudgets`
- `budgetSettings`
- `savingsSettings`
- `notificationStates`
- `displaySettings`
- `notificationSettings`
- `onboardingStates`
- `appMetadata`

Phase 8時点で作成した古いバックアップには`savingsSettings`がありません。そのバックアップを復元すると、収支・予算・設定を維持したまま、貯金設定だけ「残高0円・目標未設定」で補完します。

## 貯金機能の手動確認

### 残高と目標の設定

1. 設定タブを開きます。
2. 「貯金額・目標」を確認します。
3. 現在の貯金額へ`50000`を入力します。
4. 目標名へ「旅行資金」、目標金額へ`100000`を入力します。
5. 「貯金設定を保存」を押します。
6. ホームへ戻ります。
7. 現在残高50,000円、目標100,000円、達成率50％、残り50,000円が表示されることを確認します。

### 目標達成

1. 現在の貯金額を`125000`へ変更します。
2. ホームで達成率125％と「目標を達成しました」が表示されることを確認します。
3. 進捗バーが画面外へはみ出さないことを確認します。

### 目標削除

1. 設定で「目標を削除」を押します。
2. 確認画面で削除します。
3. 目標名と目標金額だけが消えることを確認します。
4. 現在の貯金額が残っていることを確認します。

### 入力検証

次の入力を保存できないことを確認します。

- 現在残高が空欄、負数、小数
- 目標金額が0円、負数、小数
- 目標名だけ入力
- 目標金額だけ入力
- 目標名が40文字を超える

### iPhone・テーマ

- 320px、375px、390px、430px幅
- ライトモードとダークモード
- Safe Areaと下部タブとの重なり
- 金額や長い目標名の折り返し
- ボタンの44px以上のタップ領域
- VoiceOverによる残高、目標、達成率、入力欄の読み上げ

## バックアップ・復元の手動確認

1. 貯金残高と目標を設定します。
2. 設定から全データのバックアップを作成します。
3. 貯金残高と目標を別の値へ変更します。
4. 作成したJSONを選択して復元します。
5. 貯金残高と目標がバックアップ時点へ戻ることを確認します。
6. Phase 8時点の古いJSONを選択し、残高0円・目標未設定として復元できることを確認します。

## PWAとGitHub Pages

`main`ブランチへpushすると`.github/workflows/deploy-pages.yml`がlint、型検査、テスト、ビルドを実行し、成功後にGitHub Pagesへ公開します。Viteの`base`、manifestの`start_url`と`scope`はリポジトリのサブパスに合わせて設定されます。

アプリ本体がService Workerへキャッシュ済みでIndexedDBを利用できる状態では、貯金設定、CSV、レポート、バックアップ、復元を端末内で処理できます。

## データ保存とプライバシー

収支、予算、貯金残高・目標、通知、各種設定はiPhoneまたはブラウザ内のIndexedDBへ保存します。家計簿データをGitHubリポジトリや独自の外部サーバーへ自動送信しません。

Web Share APIを選択した場合だけ、ユーザーが共有シートで選択した保存先・アプリへCSVまたはJSONファイルを渡します。ブラウザのWebサイトデータを削除した場合、端末内データも失われる可能性があるため、定期的にバックアップしてください。
